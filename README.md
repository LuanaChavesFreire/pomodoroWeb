# ⏱️ Pomodoro Web

Um **cronômetro Pomodoro simples** 100% feito com **HTML, CSS e JavaScript**, construído para praticar a **manipulação do DOM** e lógica de tempo no navegador.

Este projeto implementa a **Técnica Pomodoro**, um método de gerenciamento de tempo que ajuda a manter foco e produtividade dividindo o trabalho em blocos.

## 📌 Sobre

A Técnica Pomodoro propõe ciclos de foco intenso seguidos de pequenos intervalos para descanso. Este cronômetro permite iniciar, pausar e resetar sessões, alternando entre períodos de trabalho e descanso automaticamente. :contentReference[oaicite:0]{index=0}

O foco do projeto é reforçar habilidades em:

- Manipulação do DOM
- Eventos e lógica de tempo com JavaScript
- Estruturação de estilos com CSS
- Organização de HTML sem frameworks

## 📂 Estrutura do Projeto

| Arquivo / Pasta | Função |
|------------------|--------|
| `index.html`     | Interface principal |
| `styles.css`     | Estilos visuais e layout |
| `app/`           | Scripts JS com lógica do cronômetro |
| `imagens/`       | Imagens usadas no projeto |
| `sons/`          | Sons e alertas usados no timer |

## 🧠 Funcionalidades

✔️ Iniciar o cronômetro  
✔️ Pausar / retomar a contagem  
✔️ Alternar ciclos de foco e descanso  
✔️ Feedback visual do tempo restante  
✔️ Sons para sinalizar fim da sessão
